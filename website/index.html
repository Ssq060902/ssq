图匣 PicVault

把商品页里的图，收进你的匣子。

在电商详情页一键采集全部商品图，新开图库页预览勾选，单张导出 PNG，多张打包 ZIP。

立即安装 看怎么用

三步采完一页图

打开商品页，点扩展，在新页面勾选后下载 PNG 或 ZIP。不改站点，不需账号。

  1. 01

    打开商品详情

    进入淘宝、天猫、京东、拼多多或亚马逊等商品页，必要时滚到详情图区域。

  2. 02

    新页面预览

    点击工具栏「图匣」，自动打开图库页，列出本页全部主图与详情图，可筛选、全选或单选。

  3. 03

    PNG / ZIP 下载

    单张导出为 PNG；多张一键打包 ZIP。文件保存在「下载/PicVault」文件夹。

本地加载安装

当前以开发版分发，Chrome / Edge / 国产 Chromium 内核浏览器均可。

  1. 打开浏览器扩展管理页：chrome://extensions 或 edge://extensions
  2. 开启右上角「开发者模式」
  3. 选择「加载已解压的扩展程序」，指向项目里的 extension 文件夹
  4. 固定「图匣 PicVault」到工具栏，打开任意商品页即可使用

扩展目录： picvault/extension
